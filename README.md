# Sistema de Controle de Hotel

Projeto simples desenvolvido para a atividade prática de Gerenciamento de Configuração.

## Objetivo
Organizar informações básicas de hóspedes e demonstrar a manutenção dos artefatos de um projeto utilizando Git e GitHub.

## Arquivos do projeto
- `main.py`: cadastro e listagem simples de hóspedes.
- `nova_funcionalidade.py`: consulta da disponibilidade de quartos.
- `historico_alteracoes.md`: registro das modificações realizadas.

## Como executar
É necessário ter o Python 3 instalado. No terminal, execute:

```bash
python main.py
```
